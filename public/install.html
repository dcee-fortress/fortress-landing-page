Install Fortress

Use Fortress like an app on your phone or laptop. Same live site: fortress-zw.vercel.app

Phone — Add to Home Screen

Android (Chrome)

  1. Open the Fortress website.
  2. Menu (⋮) → Install app or Add to Home screen.
  3. Open the Fortress icon — it runs full screen like an app.

iPhone (Safari)

  1. Open the Fortress website in Safari.
  2. Share → Add to Home Screen.
  3. Open Fortress from your home screen.
Open Fortress

Laptop — Windows app

  1. Get Fortress-Setup-…exe or Fortress-Portable-…exe from the Fortress owner.
  2. Portable: double-click to run (no install).
  3. Setup: run the installer for Start Menu + desktop shortcut.

Owner builds those files with Build-Fortress-Apps.bat in the project folder.

Android APK (optional)

If you received Fortress.apk, allow install from that source, open the file, and tap Install.
